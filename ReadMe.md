## 🚀 Проекты

### 1. Online Store — Fullstack E-commerce Application  
📁 `./1.online-store-app/`

Полнофункциональный интернет-магазин с клиентской частью на React и серверной частью на Node.js + Express.

**Реализовано:**
- Аутентификация пользователей (JWT)
- Каталог товаров с фильтрацией и сортировкой
- Пагинация
- Страница товара
- Корзина с привязкой к пользователю
- Взаимодействие с PostgreSQL (Supabase)
- REST API

**Стек:**  
React, React Router, Context API, SCSS, Node.js, Express, Supabase (PostgreSQL), REST API

---

### 2. Todo List — Fullstack Task Management Application  
📁 `./2.todo-list-react/`

SPA-приложение для управления задачами с использованием Redux Toolkit и асинхронного взаимодействия с сервером.

**Реализовано:**
- CRUD-операции через REST API
- Асинхронная загрузка данных (createAsyncThunk)
- Централизованное управление состоянием
- Темная / светлая тема
- Фильтрация задач
- Клиент-серверная архитектура

**Стек:**  
React, Redux Toolkit, Axios, SCSS, Node.js, Express

---

### 3. Bank App — Fullstack Banking Application  
📁 `./3.bank-app/`

Веб-приложение для управления банковским счётом с реализацией серверной логики обработки операций.

**Реализовано:**
- Регистрация и авторизация пользователя
- Операции пополнения и списания
- Валидация баланса
- REST API
- Инкапсуляция логики работы со счётом

**Стек:**  
HTML, CSS, JavaScript, Node.js, Express
